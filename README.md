# tictactoe-cpp

Classic two-player Tic-Tac-Toe in the console, written in modern **C++17** with zero dependencies.

## Build & Run

```sh
cmake -B build
cmake --build build
./build/tictactoe
```

## Controls

Type a cell number (`1-9`):

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```
